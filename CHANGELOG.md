# Changelog

## [0.2.0] - 2026-11-01

### Qo‘shildi

- D1 va Drizzle asosidagi server backend.
- Mahsulot, kategoriya, buyurtma, buyurtma qatorlari va sozlamalar jadvallari.
- Serverda qayta hisoblanadigan checkout va qoldiqni kamaytirish.
- Foydalanuvchining backenddagi buyurtmalar tarixi.
- Himoyalangan `/admin` panel: dashboard, CRUD, buyurtma statuslari va promo sozlamalari.
- `ADMIN_EMAILS` orqali server tomonidagi admin ruxsat tekshiruvi.
- To‘liq yangi mobil UI va server API xatolariga holatlar.

### O‘zgardi

- Statik bitta HTML dastur Vinext/React Worker ilovasiga ko‘chirildi.
- Versiya `0.1.0` dan `0.2.0` ga yangilandi.
