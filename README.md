# Uzum mobil clon — v0.1.0

Mobil do'kon demosi. Uzum bilan rasmiy aloqasi yo'q. Haqiqiy to'lov va buyurtma yuborilmaydi.

## Ishga tushirish
`dist/index.html` faylini brauzerda oching yoki `python3 -m http.server 8080 --directory dist` buyrug'ini bajaring. npm yoki build kerak emas.

## Imkoniyatlar
14 ta mahsulot, qidiruv, kategoriyalar, mahsulot oynasi, sevimlilar, savat, miqdor va jami hisoblash, demo buyurtma. Kenglik 480px gacha; desktop keyinroq.

## Tuzilma
- `dist/index.html`: Sites uchun asosiy HTML, CSS va JS.
- `VERSION`: joriy versiya.
- `CHANGELOG.md`: har versiyadagi o'zgarishlar.
- `AI_CONTINUE_PROMPT.md`: boshqa AI bilan davom ettirish yo'riqnomasi.
- `AGENTS.md`: kelgusi AI uchun ish qoidalari.

React/TanStack varianti alohida [Lovable loyihasida](https://lovable.dev/projects/1d38b7b3-534e-438b-ade6-e8aa513b7f8f). Bu repository statik Sites variantini saqlaydi; avtomatik Lovable sinxronizatsiyasi yo'q.

Rasmlar Unsplash orqali internetdan yuklanadi. Shahar va profil menyusi hozircha maket. Ma'lumotlar faqat shu brauzer/origin localStorage'ida saqlanadi.
